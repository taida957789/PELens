x86/x64 disassembly from the entry point, exports or TLS callbacks, with IAT calls named; every item opens in a fast hex view.

A bounds-checked parser that never panics, fuzzed with libFuzzer, with limits against malformed tables that try to blow up the output.

Get started

  1. Download the zip from the latest release and unzip it. Nothing to install.
  2. Optionally check the download against the published SHA-256.
  3. Run pelens.exe and drop a file on the window, or use pelens-cli.exe for reports.

Windows 10/11 x64. Building from source needs Rust 1.88 or newer.

PowerShell
# verify the download
Get-FileHash PELens-*-windows-x64.zip -Algorithm SHA256

# open a file in the GUI, in Japanese, with the hex view
.\pelens.exe sample.exe -lang:ja -hex

# JSON report with YARA rules and the VirusTotal score
.\pelens-cli.exe -file:sample.exe -format:json -yara:.\rules -vt

Your knowledge base, or ours

PELens reads pestudio's XML format. It ships its own open knowledge base, built from public documentation and MITRE ATT&CK, so it works out of the box; with -xml:<dir> it uses the XML files of your own pestudio installation instead.
